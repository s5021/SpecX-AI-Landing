🌐 HOW TO VIEW THE LANDING PAGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD 1: Direct File Open (Easiest)
────────────────────────────────────────────────────────
1. Navigate to: SpecX-AI-Landing folder
2. Double-click: index.html
3. Opens in your default browser
4. Done! 🎉


METHOD 2: VS Code Live Server (Recommended for Development)
────────────────────────────────────────────────────────────
1. Open SpecX-AI-Landing in VS Code
2. Install "Live Server" extension (if needed)
3. Right-click index.html
4. Select "Open with Live Server"
5. Auto-opens at http://127.0.0.1:5500/
6. Auto-refreshes on file changes ♻️


METHOD 3: Python HTTP Server
────────────────────────────────────────────────────────
Open terminal in SpecX-AI-Landing folder:

Python 3:
    python -m http.server 8000

Then open browser:
    http://localhost:8000


METHOD 4: Node.js HTTP Server
────────────────────────────────────────────────────────
Install (one-time):
    npm install -g http-server

Run server:
    http-server -p 8000

Open browser:
    http://localhost:8000
