═══════════════════════════════════════════════════════════
📅 DAILY WORKFLOW (What You'll Use 90% of the Time)
═══════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────┐
│ 1. START YOUR DAY (Pull latest changes)                │
└─────────────────────────────────────────────────────────┘

git checkout main
git pull origin main


┌─────────────────────────────────────────────────────────┐
│ 2. CREATE NEW FEATURE BRANCH                            │
└─────────────────────────────────────────────────────────┘

git checkout -b feature/day2-javascript
                ↑         ↑
                │         └─ descriptive name
                └─ creates and switches to new branch


┌─────────────────────────────────────────────────────────┐
│ 3. CHECK WHAT YOU CHANGED                               │
└─────────────────────────────────────────────────────────┘

git status


┌─────────────────────────────────────────────────────────┐
│ 4. STAGE YOUR CHANGES                                   │
└─────────────────────────────────────────────────────────┘

git add .                    # Add all files
git add script.js            # Add specific file
git add *.js                 # Add all JavaScript files


┌─────────────────────────────────────────────────────────┐
│ 5. COMMIT YOUR CHANGES                                  │
└─────────────────────────────────────────────────────────┘

git commit -m "Day 2: Add JavaScript interactivity"


┌─────────────────────────────────────────────────────────┐
│ 6. PUSH TO GITHUB                                       │
└─────────────────────────────────────────────────────────┘

git push -u origin feature/day2-javascript
         ↑
         └─ first time pushing this branch

git push                     # After first time


┌─────────────────────────────────────────────────────────┐
│ 7. AFTER PR IS MERGED                                   │
└─────────────────────────────────────────────────────────┘

git checkout main
git pull origin main
git branch -d feature/day2-javascript


═══════════════════════════════════════════════════════════
🔍 INFORMATION COMMANDS (Check Status)
═══════════════════════════════════════════════════════════

git status                   # What's changed?
git log --oneline -5         # Last 5 commits
git branch                   # List branches
git diff                     # See changes not staged
git diff --staged            # See staged changes
git remote -v                # Show remote repositories


═══════════════════════════════════════════════════════════
🌿 BRANCH COMMANDS
═══════════════════════════════════════════════════════════

git branch                        # List all branches
git branch feature/name           # Create branch
git checkout feature/name         # Switch to branch
git checkout -b feature/name      # Create + switch
git branch -d feature/name        # Delete branch (safe)
git branch -D feature/name        # Force delete


═══════════════════════════════════════════════════════════
↩️  UNDO COMMANDS (Careful!)
═══════════════════════════════════════════════════════════

git checkout -- file.js           # Discard changes to file
git restore file.js               # Newer way (Git 2.23+)
git reset HEAD file.js            # Unstage file
git reset --soft HEAD~1           # Undo commit, keep changes
git reset --hard HEAD~1           # Undo commit, lose changes ⚠️


═══════════════════════════════════════════════════════════
📝 COMMIT MESSAGE TIPS

────────────────

────────────────

═══════════════════════════════════════════════════════════
🚨 COMMON SITUATIONS & SOLUTIONS
═══════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────┐
│ SITUATION: I made changes on the wrong branch!          │
└─────────────────────────────────────────────────────────┘

# Save your changes
git stash

# Switch to correct branch
git checkout -b correct-branch

# Apply your changes
git stash pop


┌─────────────────────────────────────────────────────────┐
│ SITUATION: I want to discard all my changes             │
└─────────────────────────────────────────────────────────┘

git checkout -- .                 # Discard all changes
git clean -fd                     # Remove untracked files


┌─────────────────────────────────────────────────────────┐
│ SITUATION: I committed to main by mistake!              │
└─────────────────────────────────────────────────────────┘

# Create branch with current state
git branch feature/fix

# Reset main to previous state
git reset --hard HEAD~1

# Switch to your branch
git checkout feature/fix


┌─────────────────────────────────────────────────────────┐
│ SITUATION: My branch is behind main                     │
└─────────────────────────────────────────────────────────┘

git checkout main
git pull origin main
git checkout feature/my-branch
git merge main


┌─────────────────────────────────────────────────────────┐
│ SITUATION: I need to change my last commit message      │
└─────────────────────────────────────────────────────────┘

git commit --amend -m "New message"

═══════════════════════════════════════════════════════════
🎓 GITHUB PULL REQUEST CHECKLIST
═══════════════════════════════════════════════════════════

Before Creating PR:
□ Code is working (tested locally)
□ No console errors
□ Code is commented
□ Commit messages are clear
□ Branch is up to date with main

PR Description Should Include:
□ What was built
□ Why it was built
□ How to test it
□ Screenshots (if UI changes)
□ Checklist of completed items


═══════════════════════════════════════════════════════════
💡 PRO TIPS
═══════════════════════════════════════════════════════════

1. Commit often! (Multiple times per day)
2. Push at least once per day
3. Always work on a branch, never on main
4. Pull main before creating new branch
5. Delete merged branches to stay organized
6. Use descriptive branch and commit names
7. Test before committing
8. Keep commits focused (one feature per commit)
